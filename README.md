# A Personal Website From Sabio

Now with React Router v8, the most peak web development framework of all time! Uranium still not included.

## How to localhost?

First, run `npm install` in the root directory of this repository. After it is complete, run `npm run dev`. You will need [Node.js](https://nodejs.org/) for this. **There is an `.env` for this repository.**

## What is this?

This is my personal website, revamped from the ground up with a minimalist look (for now...)
